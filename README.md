# DINOSCORE RAPTOR CAPTOR ROGUE LITE

A coin-flip arcade roguelite for Steam. You load a coin into a spring-tension
flip gun, set tilt, aim and power, and fire it at a wall of cursed funnels while
a rotating floor disc sweeps up everything you miss. You rig the machine, and
you still have to make the shot. Sibling of REDEMPTION ALLEY.

The repo name is not the game name. The title is undecided (D-003).
